# 雅思词境追踪局 · IELTS Vocabulary Story Lab

一个受“剧情化背词”产品机制启发的原创单页学习产品：把雅思听力、口语、阅读、写作高频词放进 8 个短篇英文剧情里，用户通过阅读、点击词汇档案、完成轻复盘来建立语境记忆。

## 功能

- 首页产品介绍、进度数据、剧情词库入口
- 8 个原创雅思剧情篇章，64 个首发词条
- 搜索、主题筛选、剧情顺序/进度/词条数排序
- 阅读器：场次切换、正文高亮词汇、剧情反转提示
- 雅思词汇档案：音标、词性、释义、常见搭配、考试场景、记忆钩子、剧情例句
- 今日雅思复盘：3 道选择题，基于已点亮词汇生成
- `localStorage` 保存学习进度，刷新页面后继续
- 响应式移动端布局和键盘焦点状态

## 本地运行

无需安装依赖，直接在项目目录执行：

```bash
python3 -m http.server 4173
```

然后打开 <http://127.0.0.1:4173/>。

## 发布

这是纯静态 HTML/CSS/JS，可直接发布到 GitHub Pages、Cloudflare Pages、Netlify 或任意静态托管。
